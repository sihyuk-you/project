# Starbound Expedition

Original 3D star-adventure prototype built with Unity.

## Scope
- Mobile touch controls and gamepad input
- Hub area and 13 original stages
- Original enemies, bosses, story, music, and save data
- Platform abstraction prepared for an authorized console SDK integration

## Important
This repository does not contain Nintendo SDK files, credentials, copyrighted Nintendo assets, or an approved console build. Install licensed SDKs only in an authorized local development environment and never commit them.
